# Krea Digital

Página web informativa para **Krea Digital** — mantenimiento web, gestión de redes sociales y creación de eventos.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React (iconos)

## Desarrollo

```bash
npm install
npm run dev
```

a
Abre [http://localhost:5173](http://localhost:5173) en el navegador.

## Build

```bash
npm run build
npm run preview
```

## Estructura

```
src/
├── components/     # Navbar, Hero, About, Services, Pricing, Footer...
├── data/           # Contenido y datos de servicios/precios
├── App.tsx
└── index.css       # Estilos globales y tema KREA
```
